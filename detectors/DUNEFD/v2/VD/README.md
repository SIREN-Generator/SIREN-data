# DUNE Far Detector FD2-VD geometry

## dunevd10kt_3view_30deg_v7_refactored_1x8x14_nowires.gdml

Geant4/LArSoft GDML of the DUNE Far Detector module 2 (FD2), the vertical-drift
(VD) liquid-argon TPC, 3-view charge-readout plane with induction strips at
30 deg. This is the `1x8x14` "workspace" (a partial-module tiling, not the full
10 kt module) in the `nowires` variant (strip solids omitted, sensitive volumes
retained) -- a lightweight geometry suited to SIREN's macroscopic-material
sector model.

### Geometry description

- `dunevd` -- FD2, vertical-drift LArTPC technology (contrast `dune10kt` = FD1
  horizontal-drift).
- `10kt` -- the nominal 10 kt fiducial-mass class of a full FD module (the
  workspace file below tiles only a partial module).
- `3view_30deg` -- the VD charge-readout plane (CRP) has three readout views
  (two induction + one collection); the induction strip views are oriented at
  +/-30 deg relative to the collection strips.
- `v7` -- geometry version 7: realistic CRP super-structure (SST) geometry and
  inter-CRP gaps (SST type 1 and type 2), plus a distinct bottom-CRP geometry.
- `refactored` -- the LArSoft RefactoredGDMLSchema layout.
- `1x8x14` -- the `workspace==1` CRP/CRM tiling: a single (top) drift volume
  8 CRMs wide x 14 CRMs long with realistic gaps. A partial-module cutout, NOT
  the full module (which is 2x8x40 with both top and bottom drift).
- `nowires` -- the per-strip / sense-wire solids are omitted (zero `<wire>`
  elements) for a lighter geometry; the sensitive `volTPCActive` volumes and
  SensDet tags are retained.

### Placement in SIREN

Loaded by `resources/detectors/DUNEFD/DUNEFD-v2/` as detector `VD` (or as part
of `both`). Site frame: +y = up, +z = LBNF beam downstream (geographic azimuth
277.15 deg, +5.71 deg upward), +x = right-handed. The VD GDML is built x = up
(vertical drift along local x), so it is placed with GDML rotation z = -90 deg
(passive), mapping local +x onto global +y: the vertical drift axis points along
+y (up), with the gaseous-argon ullage at the top.
