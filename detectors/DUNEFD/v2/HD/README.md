# DUNE Far Detector FD1-HD geometry

## dune10kt_v6_refactored_1x2x6_nowires.gdml

Geant4/LArSoft GDML of the DUNE Far Detector module 1 (FD1), the
horizontal-drift (HD) single-phase liquid-argon TPC. This is the `1x2x6`
"workspace" (a partial-module tiling, not the full 10 kt module) in the
`nowires` variant (individual sense wires omitted, sensitive volumes retained)
-- a lightweight geometry suited to SIREN's macroscopic-material sector model.

### Geometry description

- `dune10kt` -- FD1, horizontal-drift (single-phase) 10 kt module designator
  (contrast `dunevd` = FD2 vertical-drift).
- `v6` -- geometry version 6 of the HD model.
- `refactored` -- the LArSoft RefactoredGDMLSchema layout (auxiliary
  sensitive-volume tags; header
  `xs:noNamespaceSchemaLocation="RefactoredGDMLSchema/SimpleExtension.xsd"`).
- `1x2x6` -- the `--workspace=2` partial APA tiling: nAPAWide=1, nAPAHigh=2,
  nAPALong=6 (12 anode plane assemblies). A reduced cutout, NOT the full HD
  module (which is 3x2x25 APAs).
- `nowires` -- generated with wires off (the documented low-memory variant):
  individual sense wires are omitted while the TPC sensitive/active volumes
  (`volTPCActive`) are retained. The wires-on counterpart is
  `dune10kt_v6_refactored_1x2x6.gdml` at the same commit.

### Placement in SIREN

Loaded by `resources/detectors/DUNEFD/DUNEFD-v2/` as detector `HD` (or as part
of `both`). Site frame: +y = up, +z = LBNF beam downstream (geographic azimuth
277.15 deg, +5.71 deg upward), +x = right-handed. The HD GDML is already in this
frame (y = up, z = beam), so it is placed with identity rotation.
